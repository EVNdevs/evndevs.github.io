Example programs

The same examples the VS Code extension lists under Examples: for every part of the robot a minimal and a complete program, in Python and, where there are blocks for it, in blocks. Download one and open it in the extension (a .evnblocks file opens in the blocks editor). Needs says what to plug in, and how to set the robot up, before you run it.

Robot (DriveBase) two wheel motors driven together

  • Robot: minimalrobot_minimal.py · robot_minimal.evnblocksNeeds: a robot: left wheel motor on port 4 (mounted mirrored), right on port 3, 62.4 mm wheels 170 mm apart, and 40 cm of clear floor ahead
    Python Blocks
  • Robot: the whole DriveBase APIrobot_complete.py · robot_complete.evnblocksNeeds: a robot: left wheel motor on port 4 (mounted mirrored), right on port 3, 62.4 mm wheels 170 mm apart, an EVN IMU on I2C port 3 fixed flat to the chassis, and 40 cm of clear floor ahead and 20 cm to each side (the robot also pivots about 45 degrees on its right wheel and back). Keep the robot still while the program starts: the IMU calibrates its gyro 8 to 25 s into stillness.
    Python Blocks
