# EVN ALPHA MicroPython

The documentation site, the firmware and the VS Code extension releases of the EVN ALPHA MicroPython
project. Read the documentation at <https://evn.coresg.tech>.

| Path | What it is |
| :--- | :--- |
| `docs/` | the getting-started guide, the API reference and the blocks reference (the site renders these) |
| `examples/` | the example programs the extension bundles |
| `firmware/` | the compiled MicroPython firmware (`.uf2`) and its build record |
| `latest.json` | the version manifest the extension's update check reads |
| `index.html` | the documentation site itself (one file, no build step) |

The packaged extension (`.vsix`) is attached to each [release](https://github.com/EVNdevs/vscode-evn-alpha/releases).
