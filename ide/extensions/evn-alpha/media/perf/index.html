Time this device

This page runs the simulator's challenge levels the way the Simulator panel does, on this device, and times each run. It sends nothing anywhere. At the end it shows a record: save it or copy it, and send it to whoever compares it with the PC (node scripts/perf_page.js --compare).

Keep the page in front and the screen on while it runs: a browser slows a page it hides, and such a run is not counted. A polling program on a long level takes minutes a run. EVN ALPHA .
